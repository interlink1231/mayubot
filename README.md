# MAYUBOT

한국 Discord 서버를 위한 보안 전용 봇입니다. Python과 discord.py로 독립 구현합니다.

## V1.0 범위
- 악성유저 스캔: MAYUBOT 자체 검토 목록과 서버 구성원 대조
- 타 서버 초대 링크 검열
- 도배·단타 및 과도한 멘션 검열
- 서버 테러 징후 감지 및 관리자 알림
- 운영자가 작성한 보안 리포트 공지
- 권한 검증을 거치는 자연어형 메시지 명령
- Discord 서버 태그 감지 및 역할 자동 관리

보안과 무관한 유틸리티, 경제, 음악, 게임, 레벨 기능은 포함하지 않습니다.

## 중요 안내
MAYUBOT은 SORI의 공개 기능 설명을 참고해 별도로 구현하는 프로젝트입니다. SORI의 소스 코드, 비공개 데이터베이스 또는 블랙리스트 데이터는 사용하지 않습니다. 초기 악성유저 목록은 MAYUBOT 운영자가 별도로 검토·관리하는 데이터만 사용합니다. 외부 글로벌 데이터베이스가 연결된 것처럼 표시하지 않습니다.

악성유저 스캔은 관리자에게 참고 정보를 제공하며, 스캔 결과만으로 자동 추방·차단하지 않습니다. 오탐 방지를 위해 근거 검토와 이의제기 절차를 마련해야 합니다.

## 실행
1. Python 3.11 이상 설치
2. pip install -r requirements.txt
3. .env.example을 .env로 복사하고 DISCORD_TOKEN 설정
4. Discord Developer Portal에서 Server Members Intent와 Message Content Intent 활성화
5. python main.py 실행
